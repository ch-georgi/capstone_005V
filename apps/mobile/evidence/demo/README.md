# Mockup Android sin conexión

Validado el 15 de octubre de 2026 en el emulador Android 15 propio del proyecto, con modo avión y Wi-Fi/datos deshabilitados. El APK contiene demoMode=true. Se verificaron login con la cuenta ficticia, bienvenida personalizada, logout y vuelta al login al reiniciar. Las capturas son originales del emulador. No se requirió API ni conexión PostgreSQL.

Ver validation.json y la sección de mockup del README móvil para credenciales y activación/desactivación. La sesión demo vive solo en memoria y no modifica SecureStore. APK firmado para pruebas, sin verificación en teléfono físico.
